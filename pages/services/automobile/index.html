Какая разница между автотехнической и автотовароведческой?

Автотехническая (16 вопросов) — для споров о виновности в ДТП. По ФЗ-73. Автотовароведческая (10 вопросов) — для споров со страховой о выплате по ОСАГО/КАСКО. По Методике Минюста № 154.

По какой методике проводите?

Автотехническая — по ФЗ-73. Автотовароведческая — по Методике Минюста № 154. Узлы и агрегаты — по ГОСТ и ТУ.
