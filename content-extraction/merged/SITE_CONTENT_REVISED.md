Ситуация → род → (категория — только для товароведческой) → формат.
Формат определяется стадией спора, не выбором пользователя:

- оппонент уже представил заключение → **рецензия**
- дело в суде / назначена судебная экспертиза → **судебная**
Правила связей: описание рода — только на странице рода; цены — только в матрице цен (§16); кейсы — по ситуациям/категориям; сравнение форматов — только на ситуациях; калькулятор возврата — только на ситуациях.
