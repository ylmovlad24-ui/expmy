# README: рецензент.рус — лендинг рецензирования судебных экспертиз (1С‑Битрикс)

## Назначение проекта
Лендинг для привлечения клиентов, которым нужно оспорить судебную экспертизу в суде (в т.ч. по ДТП, узлам/агрегатам, товароведению).  
Главная цель страницы — конверсия в заявку на разбор заключения.  

**CMS:** 1С‑Битрикс (перенос структуры и контента в композитный сайт).  
**Инструменты разработки:** GigaCode / GigaIDE (генерация JSON‑структур, текстов, компонентов, ТЗ для инфоблоков).

---

## Единый визуальный стиль (для всех страниц второго уровня и главной)

Все страницы используют **один базовый шаблон** с унифицированными блоками. Это даёт предсказуемый UX и снижает объём правок при поддержке.

### CSS‑переменные (глобальные)
```css
:root {
  --bg: #F8F9FA;
  --text: #333333;
  --primary: #2A5B9A;
  --accent: #E67E22;
  --border: #E0E4E8;
  --card-radius: 8px;
  --section-gap: 72px; /* отступ между секциями */
  --inner-gap: 24px;   /* отступ внутри секции */
}
```

### Компоненты
- `.rc-card` — универсальная карточка (фон #fff, рамка, border-radius 8px, padding 24px, hover-эффект).
- `.section-title` — заголовок секции (2rem, 700, centered).
- `.checklist__list` / `.checklist__item` — чек-лист с иконкой ✓ (синий круг).
- `.faq__item` — аккордеon через `<details>/<summary>`.
- `.trust__items` — сетка из 3 колонок с иконками и заголовками.
- `.header` / `.footer` — sticky header и footer, grid 4 колонки.

### Типографика
- H1: 2.5rem, 700 (page-header) / 2rem (секции)
- H2: 1.25rem–1.5rem, 600
- H3: 1.1rem–1.15rem, 600
- Текст: 0.95rem–1.05rem, 400
- Ссылки CTA: 0.9rem, 600, accent color

  - `hero__cta--secondary` (оранжевая): «Заказать рецензию» → `/services/`

### 3 плитки направлений
- Карточки `.rc-card` с иконкой, заголовком, описанием, CTA «Подробнее →»
- Ссылки на `/services/dtp/`, `/services/units/`, `/services/commodity/`

1. Проверяем соответствие методик и нормативов

3. Выявляем методические ошибки
4. Проверяем логику выводов эксперта

- Одна карточка `.rc-card case-card` с описанием результата

### Блок «Сотрудничество с юрфирмами»
- 3 тезиса в grid: «Специальные условия», «Совместная работа», «Расширение услуг»

- Что такое рецензия?
- Сколько стоит?
- Какие сроки?
- Принимается ли в суде?
- Какие документы нужны?

- Поле «Опишите вашу ситуацию» (textarea)

### Footer

- Юридические ссылки: Политика конфиденциальности, Договор-оферта
- Контакты

5. **Доверие** — 3 тезиса в grid: «Работаем по договору», «Конфиденциальность», «Подходит для ходатайства»
6. **Footer** — стандартный

## Детальная страница услуги `/services/{slug}/`

Блоки в том же едином стиле:

1. **H1 + H2** — название услуги и подзаголовок (например: «Рецензия по ДТП» / «Оспариваем экспертизы по дорожно-транспортным происшествиям»)
2. **«Что проверяем»** — чек-лист 5 пунктов с иконками ✓
3. **«Что вы получаете»** — 3 карточки `.rc-card`:
   - «Заключение рецензента»
   - «Перечень ошибок»
   - «Рекомендации для ходатайства»
4. **Сроки и стоимость** — 3 карточки:
   - Стоимость (от 15 000 ₽)
   - Стандартный срок (1–3 дня)
   - Экспресс-разбор (24 часа)
5. **Кейсы по направлению** — 1 обезличенная карточка
6. **Локальный FAQ** — 3–4 вопроса-аккордеона
7. **Форма заявки** — имя + телефон + текст + чекбокс; CTA «Отправить заявку» + текст «Или позвоните — разберём ситуацию за 5 минут»
8. **Доверие** — те же 3 тезиса
9. **Footer** — стандартный

### Отличия по направлениям:
| Параметр | ДТП | Узлы/агрегаты | Товароведение |
|----------|-----|----------------|---------------|
| Иконка | 🚗 | ⚙️ | 📦 |
| Специфика чек-листа | ГОСТ, формулы | Измерения | Нормативы |
| Пример кейса | Оспорена экспертиза по ДТП | Оспорена экспертиза по узлам | Оспорена товароведческая экспертиза |
| FAQ вопросы | ДТП-специфичные | Узлы-специфичные | Товароведческие |
