Политика конфиденциальности

Общие положения

Настоящая Политика конфиденциальности определяет порядок обработки и защиты персональных данных пользователей сайта «Рецензент.рус» (далее — Сайт), расположенного по адресу рецензент.рус.

Используя Сайт, вы соглашаетесь с условиями данной Политики конфиденциальности и даёте согласие на обработку ваших персональных данных в соответствии с Федеральным законом № 152-ФЗ «О персональных данных».

1. Какие персональные данные мы собираем

Мы можем обрабатывать следующие персональные данные:

  • Имя — для идентификации пользователя и обработки заявок;
  • Номер телефона — для обратной связи и консультации;
  • Адрес электронной почты — для отправки ответов на заявки и информационной переписки;
  • Сообщение — описание ситуации, с которой пользователь обращается;
  • Данные о посещении — IP-адрес, тип браузера, страница, время посещения (через средства аналитики).

2. Цели обработки персональных данных

Персональные данные обрабатываются в следующих целях:

  • Обработка входящих заявок и обратная связь с пользователями;
  • Предоставление информации об услугах и консультация;
  • Выполнение обязательств, предусмотренных договором-офертой;
  • Улучшение качества обслуживания и функциональности Сайта;
  • Аналитика посещений и повышение удобства использования Сайта;
  • Исполнение требований законодательства Российской Федерации.

3. Правовые основания обработки

Обработка персональных данных осуществляется на основании:

  • Согласия субъекта персональных данных, выраженного при заполнении форм на Сайте;
  • Договора-оферты, акцептованного пользователем;
  • Законных интересов оператора по предоставлению услуг;
  • Требований действующего законодательства РФ.

4. Порядок сбора и хранения

Персональные данные собираются исключительно добровольно при заполнении пользователем форм обратной связи, заявок на консультацию или заказ услуги.

Данные хранятся в защищённых базах данных на территории Российской Федерации в соответствии с требованиями Федерального закона № 152-ФЗ.

Срок хранения персональных данных определяется целью обработки и не превышает срок, необходимый для достижения этих целей, либо срок действия согласия пользователя.

5. Защита персональных данных

Оператор принимает необходимые организационные и технические меры для защиты персональных данных от несанкционированного доступа, утраты, изменения, блокирования, копирования и распространения:

  • Шифрование передаваемых данных (протокол HTTPS);
  • Ограничение доступа к данным неавторизованных лиц;
  • Регулярный контроль защищённости информационных систем;
  • Обработка данных на серверах, расположенных на территории РФ.

6. Передача данных третьим лицам

Мы не продаём, не обмениваем и не передаём ваши персональные данные третьим лицам за исключением случаев:

  • Передача данных контрагентам для оказания услуг (например, хостинг-провайдерам), при условии наличия договоров на обработку;
  • Передача данных по требованию уполномоченных государственных органов;
  • Передача агрегированных обезличенных статистических данных для аналитики.

7. Права пользователя

Пользователь имеет право:

  • Получать информацию об обработке своих персональных данных;
  • Требовать уточнения, блокирования или уничтожения персональных данных;
  • Отозвать согласие на обработку персональных данных, обратившись по электронной почте info@рецензент.рус;
  • Обратиться с жалобой в Роскомнадзор.

8. Файлы cookie

Сайт может использовать файлы cookie для обеспечения корректной работы и анализа посещаемости. Пользователь может отключить использование cookie в настройках своего браузера. Отключение cookie может ограничить некоторые функции Сайта.

9. Изменение Политики конфиденциальности

Оператор оставляет за собой право вносить изменения в настоящую Политику конфиденциальности. Новая версия Политики вступает в силу с момента её размещения на Сайте. Рекомендуем регулярно проверять данную страницу на наличие обновлений.
