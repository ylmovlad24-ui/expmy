# Анализ конверсии сайта «Рецензент.рус»

> Дата: 2026-08-22 | Тип: UX/CRO-аудит

---

## 1. Общее впечатление

Проект представляет собой многостраничный сайт юридической/экспертной тематики — рецензирование судебных экспертиз. Визуально сайт выполнен качественно: современный дизайн, плавные анимации, адаптивная вёрстка, калькулятор-квиз. Однако с точки зрения **максимизации конверсии** выявлен ряд критических и важных проблем.

---

## 2. Ключевые проблемы конверсии (приоритетные)

### 🔴 Критические

#### 2.1. Форма заявки не отправляется на backend (P0)
**Где:** Все страницы — `action="#"` у всех `<form>`.
**Проблема:** При отправке формы показывается `alert()` через 800 мс. Данные никуда не уходят.
**Влияние на конверсию:** 100% заявок теряются. Пользователь думает, что заявка отправлена, но менеджер ничего не получает.
**Решение:** Реализовать отправку через fetch на бэкенд (PHP/Node) или через сервис форм (Formspree, Telegram Bot API). Страница `/thank-you/` должна открываться только после успешной отправки.

#### 2.2. Нет redirect на thank-you после успешной отправки
**Где:** `js/script.js`, форма заявки.
**Проблема:** После «отправки» форма сбрасывается, но пользователь остаётся на той же странице. Нет подтверждения (thank-you page) и нет перехода.
**Влияние:** Пользователь не понимает, успешно ли отправлена заявка. Нет замкнутого цикла конверсии.
**Решение:** После успешной отправки — редирект на `/thank-you/` или показ inline-сообщения «Спасибо! Мы перезвоним...».

#### 2.3. Hero-блок: две CTA-кнопки размывают цель (P1)
**Где:** `index.html`, секция `.hero`.
**Проблема:** Две кнопки: «Бесплатная консультация» (якорь `#form`) и «Заказать рецензию» (`/services/`). Две разные цели для одного экрана.
**Влияние на конверсию:** Paradox of choice — пользователь колеблется и может не нажать ни на одну.
**Решение:** Одна главная CTA (например, «Получить бесплатную консультацию»), вторичная — менее контрастная (ссылка под кнопкой: «Узнать стоимость →»).

#### 2.4. Калькулятор-квиз: на шаге 4 нет предварительной цены (P1)
**Где:** `js/script.js`, шаг 4 квиза.
**Проблема:** На шаге 3 кнопка «Рассчитать» вызывает `calculatePrice()`, но результат цены показывается только на шаге 4 в карточке `quiz-calc__result-price-final`. Пользователь на шаге 3 не видит, сколько будет стоить, прежде чем введёт телефон.
**Влияние:** Пользователь может отказаться на шаге 4, не зная цену заранее — высокий drop-off.
**Решение:** Показать цену на шаге 3 перед кнопкой «Рассчитать», либо на шаге 4 — крупнее и с обоснованием.

### 🟡 Важные

#### 2.5. Телефон в хедере — не кликабельный на десктопе (P2)
**Где:** `components/header.html`.
**Проблема:** Телефон `+7 960 998-77-88` оформлен как `<a href="tel:...">` — это хорошо, но на десктопе он может быть не заметен из-за малого контраста по сравнению с CTA-кнопкой.
**Решение:** Убедиться, что телефон визуально выделяется. На мобильном — sticky-кнопка звонка внизу экрана.

#### 2.6. Нет виджета онлайн-чата / обратного звонка (P2)
**Где:** Весь сайт.
**Проблема:** Единственный способ связи — форма. Нет кнопки «Заказать обратный звонок», нет виджета чата (Jivo, Talk-Me и т.п.).
**Влияние:** Пользователи, которые хотят поговорить с живым человеком, уходят.
**Решение:** Добавить виджет онлайн-чата или кнопку «Заказать звонок» (popup с полем телефона и таймером «перезвоним за 2 минуты»).

#### 2.7. Нет социальных доказательств — отзывы, сертификаты, логотипы клиентов (P2)
**Где:** Главная страница.
**Проблема:** Есть блок «Сотрудничество с юрфирмами», но нет:
- Отзывов клиентов
- Сертификатов экспертов
- Логотипов компаний-клиентов
- Судебных решений, где рецензия была принята
**Влияние:** В юридической/экспертной тематике доверие — ключевой фактор конверсии. Без него конверсия падает на 40-60%.
**Решение:** Добавить секцию с отзывами (минимум 3-5), сертификатами, логотипами.

#### 2.8. Форма заявки на главной — слишком длинная (P3)
**Где:** `index.html`, секция `.request-form`.
**Проблема:** 3 поля (имя, телефон, сообщение) + чекбокс. Для главной страницы — поле «Опишите вашу ситуацию» создаёт барьер.
**Влияние:** Пользователь на главной может не хотеть подробно описывать ситуацию — он на этапе исследования.
**Решение:** На главной — минимальная форма: только телефон (или телефон + имя). На детальных страницах услуг — полная форма.

#### 2.9. FAQ слишком короткий для SEO и доверия (P3)
**Где:** Главная страница — 5 вопросов.
**Проблема:** Для NLP-поиска и для снятия возражений — недостаточно. Пользователи ищут конкретные вопросы, и если их нет на странице — уходят.
**Решение:** Расширить FAQ до 10-15 вопросов, включая вопросы по ценам, срокам, гарантиям.

## 3. Positive findings (что работает хорошо)

### ✅ Сильные стороны

1. **Калькулятор-квиз** — отличный инструмент генерации лидов. 4-шаговая форма с прогресс-баром вовлекает пользователя и повышает качество лида.
2. **Секция «Как мы проверяем»** — чек-лист с галочками хорошо снимает возражение «что вы делаете?».
3. **Hero-блок** — сильный H1 с эмоциональным триггером («несправедливую»), статистика (15+ лет, 500+ рецензий, 95% успешных дел).
4. **Страница «Спасибо»** — есть, но пустая.
5. **Адаптивность** — медиа-запросы для tablet, mobile, small mobile.
6. **Sticky header** — навигация всегда доступна.
7. **Телефон в хедере** — кликабельный `tel:` ссылка.
8. **Footer с контактами** — телефон, email, соцсети всегда видны.
9. **Квиз с маской телефона** — хорошая UX-деталь.
10. **Анимации** — fade-in, hover-эффекты, scroll-reveal — повышают восприятие качества.

## 5. Технические проблемы, влияющие на конверсию

### 5.1. Отсутствуют мета-теги
- **Нет `meta description`** — снижает CTR из поисковой выдачи на 20-30%
- **Нет Open Graph** — ссылки в соцсетях выглядят безлико
- **Нет favicon** — сни��ает доверие
- **Нет JSON-LD** — нет расширенных сниппетов в Google/Yandex

### 5.2. Нет аналитики
- **Нет Яндекс.Метрики / Google Analytics** — невозможно отслеживать конверсии
- **Нет целей** (цель «отправка формы», цель «прохождение квиза»)
- **Нетheatmap-аналитики** (Яндекс.Метрика Webvisor, Hotjar)

### 5.3. Нет A/B тестирования
- Нет возможности тестировать заголовки, CTA, формы

## 7. Прогноз влияния на конверсию

| Мероприятие | Прогнозируемый рост конверсии | Сложность |
|-------------|------------------------------|-----------|
| Работа форм (backend) | +50% (сейчас 0% конверсий) | Средняя |
| Метрика + цели | Не применимо (аналитика) | Низкая |
| Одна CTA в hero | +15-25% | Низкая |
| Отзывы клиентов | +20-40% | Средняя |
| Онлайн-чат | +10-20% | Низкая |
| Метатеги + SEO | +15-30% трафика | Низкая |
| SVG-иконки вместо эмодзи | +5-10% доверия | Низкая |
| Расширенный FAQ | +10% SEO, +5% доверия | Низкая |
| Показ цены в квизе | +15% завершение квиза | Низкая |

**Общий прогноз:** При реализации рекомендаций срочного и важного приоритета — рост конверсии с 0% (нет backend) до 3-8% (средний показатель для экспертных услуг).

## 8. Дополнительные рекомендации

### 8.1. Доверие и авторитет
- Добавить фото экспертов (хотя бы одно с именем и регалиями)
- Упомянуть конкретные вузы, где преподавали/работали эксперты
- Добавить номера аттестатов аккредитованных экспертов
- Упомянуть конкретные суды, где принимались рецензии

### 8.2. Триггеры срочности
- «Оставьте заявку сегодня — получите консультацию бесплатно»
- «Экспресс-разбор за 24 часа — только 3 слота в неделю»
- Таймер обратного отсчёта на странице с акцией

### 8.3. Снижение барьеров
- «Бесплатная первичная консультация» — не «Бесплатная консультация»
- «Гарантия качества или вернём деньги»
- «Первый анализ — бесплатно»

### 8.4. Мобильная оптимизация
- Sticky CTA-кнопка внизу экрана на мобильных
- Убрать анимации на мобильных для ускорения
- Увеличить touch-targetы кнопок до 48px
